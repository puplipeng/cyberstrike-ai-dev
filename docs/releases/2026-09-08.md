本轮在独立源码副本中整理，不改写现有部署的配置或数据。原有 CI 的 PostgreSQL、Linux 兼容修复保留。

## Windows 部署说明

从 `config.example.yaml` 创建自己的 `config.local.yaml`，配置 PostgreSQL、模型通道及可选的本地向量服务；数据库部署要求见 [LOCAL_POSTGRES.md](../LOCAL_POSTGRES.md)。编译命令：

```powershell
go build -o cyberstrike-ai.exe ./cmd/server
```

`scripts/start-windows-local.ps1` 是已安装环境的启动器，不是完整安装包。使用前请检查脚本约定：仓库的父目录下放置 `runtime/pgsql`、`pgdata`、`runtime/ollama-v0.33.1`、模型目录及日志目录；监听端口默认是 8080 和 11435。它会请求管理员权限，且不接管端口上的未知进程。

工具安装脚本支持 `-RuntimeRoot` 自定义路径。依赖外部兼容 runner 的 cloudmapper、hashpump、hydra、libc-database、steghide 在公开示例中默认关闭；安装对应 runner 并校正配置路径后再启用。平台源码不包含个人机器上的外部工具环境。
