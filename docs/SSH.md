# SSH / SFTP 连接

在 **WebShell 管理 → SSH / SFTP** 中添加连接。原 WebShell 连接和工具保持不变。

## 使用

1. 填写名称、主机 IP/域名、端口、用户名，选择密码或私钥。支持带口令的 OpenSSH 私钥。
2. 保存后点“核验主机指纹”。通过服务器控制台或管理员独立核对 SHA256 指纹，再点“确认信任此指纹”。探测阶段不发送登录凭据。
3. “测试登录”只验证认证，不执行命令。“打开终端”建立远程交互式 PTY，支持键盘输入、Ctrl+C 和窗口调整。Windows 部署也可连接远端 SSH。
4. SFTP 面板可浏览目录，点击文件名下载。先打开并确认目标目录，再通过“上传新文件”上传。编辑路径会清空旧列表；迟到的目录响应不会覆盖新导航。最大文件 16 MiB，同名文件不覆盖；远端须启用 SFTP。

编辑连接时凭据留空表示保留。改变主机或端口会清除已确认指纹。服务器指纹变化时连接会被拒绝，必须重新独立核验。

## 权限和安全

- 复用 WebShell 权限：查看连接需 read，认证、终端和所有 SFTP 操作需 write，删除连接需 delete。
- 连接属于创建者；具有相应全局权限的用户也可管理。当前不提供 SSH 连接的项目分配或共享功能。
- 密码、私钥和私钥口令以 AES-256-GCM 加密存入 PostgreSQL，使用连接 ID 作为附加认证数据；列表及保存响应不返回这些字段。
- 主密钥位于配置文件所在目录的 data/ssh-vault/master.key。Windows 通过 ACL 仅授权运行账号、SYSTEM 和管理员；Unix 使用目录 0700、文件 0600。请与数据库一起备份，但分开保管，勿提交 Git。
- 已有连接但主密钥丢失时不会自动生成替代密钥。恢复原密钥前凭据无法使用。
- 网页终端使用 HttpOnly、SameSite=Strict、有效期 30 秒的一次性 cookie 票据，并检查同源 Origin；登录令牌不放入 URL。
- 每账号最多 4 个并发操作，全局最多 16 个；终端最长 30 分钟。离开页面会关闭终端，连接修改/删除会取消相关操作。活动会话每 15 秒检查登录有效性和连接版本。
- 审计记录连接维护、指纹确认、登录测试、终端打开/关闭及文件操作。不会记录终端键盘输入或内容，避免保存交互式密码。
- 网页终端使用服务端直连远端 SSH，不启动本机 ssh 命令。SSH 能操作的文件和命令由远端账号权限决定。

## 限制

目前不包括跳板机、端口转发、SSH Agent 转发、多因素交互认证、远程文件编辑/删除，以及 SSH 连接的 AI 自动执行。
目录面板最多展示 1000 项。枚举使用独立 SFTP 子系统，在读取层限制元数据总量为 1 MiB、单报文为 256 KiB；最多读取一个额外的有界批次以判断是否截断，不再扫描整个大目录。达到条目或字节预算时会显示部分结果；首个报文就超出预算则拒绝该目录响应。
文件操作最长 45 秒。上传同时设置 HTTP 请求体的读取期限；超时、删除连接或服务关闭会中断读取并释放操作名额。上传中断会尝试清理新建文件；网络已经断开时可能保留部分文件，需要手动检查。
公开部署应使用 HTTPS/WSS；反向代理需支持 WebSocket Upgrade。当前本机部署仅监听 127.0.0.1。

## 测试依据

测试使用随机端口的 loopback SSH 服务和内存 SFTP 文件系统，只回显固定测试文本，不执行操作系统命令、不访问真实远程主机。
覆盖密码/加密私钥、认证前指纹拦截、握手取消、凭据加密和重启读取、权限与修订号、SFTP 往返、防覆盖、PTY、票据来源/重放以及会话清理。新增回归覆盖停滞/截断上传、取消后名额释放、目录条目和元数据预算，以及前端目录绑定、响应乱序和退出清理。
